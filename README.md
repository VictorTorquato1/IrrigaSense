# IrrigaSense

## Integração Supabase

O projeto continua sendo um frontend estático e usa `@supabase/supabase-js` e
Chart.js por CDN. O navegador não consegue ler um arquivo `.env` sozinho. Em
produção, injete as variáveis públicas no HTML antes de `JS/script.js`:

```html
<script>
	window.IRRIGASENSE_CONFIG = {
		url: "https://uttgbuwdciegxvzytepk.supabase.co/",
		anonKey: "sb_publishable_8a4KAGBZTpEnBk1yU5eaqw_1CuwyBcB"
	};
</script>
```

Os nomes equivalentes no ambiente de hospedagem são `SUPABASE_URL` e
`SUPABASE_ANON_KEY`. A `anonKey` pode aparecer no frontend quando o RLS está
corretamente configurado. Nunca use `SUPABASE_SERVICE_ROLE_KEY` no navegador.

Sem essa configuração, o dashboard local e a Web Serial continuam funcionando,
mas histórico e persistência remotos ficam desativados.

### Banco e RLS

Execute no SQL Editor do Supabase:

```sql
create table if not exists public.leituras (
	id bigint generated by default as identity primary key,
	created_at timestamptz not null default now(),
	vazao numeric(10,2) not null,
	agua_usada numeric(10,2) not null default 0,
	bomba_ligada boolean not null default false
);

alter table public.leituras enable row level security;

create policy "leituras_publicas_select"
	on public.leituras for select
	to anon, authenticated
	using (true);

create policy "leituras_publicas_insert"
	on public.leituras for insert
	to anon, authenticated
	with check (vazao >= 0 and agua_usada >= 0);
```

Se as políticas já existirem, não execute os respectivos `create policy`
novamente. O código limita os inserts a uma leitura a cada cinco segundos por
sessão do navegador e registra falhas no console sem interromper o ESP32.

### Executar localmente

Abra o projeto por um servidor HTTP local, pois Web Serial exige contexto seguro
(localhost é aceito). Por exemplo, com Python instalado:

```powershell
py -m http.server 8000
```

Depois acesse `http://localhost:8000` em um navegador Chromium compatível com
Web Serial. Configure `window.IRRIGASENSE_CONFIG` antes de abrir a página para
habilitar Supabase.
